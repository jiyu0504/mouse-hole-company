# 같이갈개 🐾

> 반려동물과 함께 갈 수 있는 서울의 카페와 명소를 찾아 주는 모바일 웹 서비스

**mouse-hole-company** 팀의 웹 프로젝트 실습 결과물입니다.
반려동물 동반 가능 여부, 크기 제한, 목줄 의무 같은 조건은 매장마다 달라서 방문 전에 일일이 확인하기 번거롭습니다. 같이갈개는 이런 조건을 한곳에 모아 조건별로 걸러 볼 수 있게 만들었습니다.

## 주요 기능

- **오늘의 추천 카페**: 홈 화면에서 하루마다 바뀌는 추천 카페 4곳을 보여줍니다.
- **카페 / 명소 목록**: 반려동물 동반 카페 156곳과 야외 명소 49곳을 지역(시·군·구)별로 볼 수 있습니다.
- **세부 조건 필터**: 아래 조건을 조합해서 검색할 수 있습니다.
  - 종: 개, 고양이
  - 크기: 소형견, 중형견, 대형견
  - 편의 시설: 주차 가능, 야외 공간, 오프리쉬
  - 기타 조건: 접종 완료, 공격성 없음, 중성화 완료, 맹견 아님
- **상세 페이지**: 주소, 전화, 홈페이지, 영업시간, 휴무일, 이용료, 입장 제한 사항을 확인할 수 있고, 카페에서는 5km 이내 주변 명소도 함께 보여줍니다.
- **후기와 별점**: 카페별로 후기를 쓰고 평균 별점을 확인할 수 있습니다.
- **찜한 매장 / 최근 본 매장**: 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.
- **로그인 / 회원가입 / MY 페이지**

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 마크업 | HTML5 |
| 스타일 | CSS3 (모바일 우선, 하단 탭 내비게이션) |
| 로직 | Vanilla JavaScript (프레임워크·빌드 도구 없음) |
| 데이터 | JSON 파일 (`fetch`로 로드) |

## 실행 방법

데이터를 `fetch`로 불러오기 때문에 `index.html`을 더블클릭(`file://`)해서 열면 동작하지 않습니다. 로컬 서버로 실행해 주세요.

```bash
# 프로젝트 폴더에서
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속하면 됩니다.
VS Code를 쓴다면 **Live Server** 확장으로 `index.html`을 열어도 됩니다.

## 데이터 구조

두 JSON 파일은 같은 스키마를 씁니다. `app.js`의 `normalize()`가 화면용 객체로 한 번 변환하므로, JSON 구조가 바뀌어도 이 함수만 고치면 됩니다.

```jsonc
{
  "id": 1,
  "name": "매장 이름",
  "location": { "sigungu": "중구", "dong": "신당동", "roadAddress": "...", "lat": 37.56, "lng": 127.01 },
  "contact":  { "phone": "...", "homepage": "..." },
  "hours":    { "closedDays": "매주 월요일", "text": "화~일 18:00~02:00", "byDay": { "mon": "휴무", "...": "..." } },
  "facility": { "parking": "Y", "admissionFee": "변동", "indoor": "Y", "outdoor": "N" },
  "conditions": { "size": { "small": "Y", "medium": "Y", "large": "Y" }, "leash": "N", "vaccinationDisease": "N" },
  "originalText": { "size": "모두 가능", "restrictions": "제한사항 없음" }
}
```

## 현재 한계와 앞으로 할 일

- 로그인과 회원가입은 화면만 구현된 상태로, 실제 인증은 하지 않습니다. 서버가 생기면 연동할 예정입니다.
- 후기는 메모리에 저장되는 샘플 데이터라서 새로고침하면 사라집니다. 서버가 생기면 `reviews` 부분만 교체하면 됩니다.
- 지도 기능은 아직 없습니다. 좌표(`lat`, `lng`)는 이미 데이터에 있어서 지도 API를 붙일 수 있습니다.
